## Overview

Implementasi fitur registrasi user dengan password hashing menggunakan bcrypt.

## Changes

### Database
- Ubah tabel users: name/email jadi varchar(255), tambah kolom password, hapus updated_at
- Hapus data contoh lama
- Migrasi berhasil diterapkan ke Supabase

### New Files
- **src/services/users-service.ts** — Service untuk registrasi user
  - Email validation (cek duplikat)
  - Password hashing dengan Bun.password.hash (bcrypt)
  - Error handling untuk email sudah terdaftar
  
- **src/routes/users-route.ts** — Route handler untuk POST /api/users
  - Input validation (name, email, password harus diisi)
  - Error handling dengan response yang sesuai
  - HTTP status 400 untuk error, 500 untuk unexpected error

- **scripts/clear-data.ts** — Helper script untuk hapus data
- **scripts/check-user.ts** — Helper script untuk verifikasi password hash

### Modified Files
- **src/schema.ts** — Update users table definition
- **src/index.ts** — Mount users route di /api/users, hapus updatedAt dari PUT /users
- **drizzle/0001_alter_users.sql** — Migration file
- **drizzle/meta/_journal.json** — Update migration journal

## API Endpoint

### POST /api/users

Register user baru

**Request:**
```json
{
  "name": "Eko",
  "email": "eko@localhost",
  "password": "rahasia"
}
```

**Success Response (200):**
```json
{
  "data": "OK"
}
```

**Error Response - Email Duplikat (400):**
```json
{
  "error": "Email sudah terdaftar"
}
```
